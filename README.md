# my-portfolio

Scaffold of a personal developer portfolio using Next.js, TypeScript, Tailwind CSS, App Router and a Catppuccin Mocha theme.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

Notes

- This repo includes a minimal homepage and a small `Button` component. Install dependencies locally and run the dev server.
- To add `shadcn/ui` components, follow their setup after installing Tailwind and required packages.
